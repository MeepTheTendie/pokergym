# Unprompted requests for more — evidence log

This is the evidence file for the Pro-unlock gate defined in `LAUNCH.md` (step 4) and
`SCORECARD.md` (targets, "Unprompted requests").

## Rule (read before adding a row)

- A request counts **only if the player wrote it unprompted**. If Poker Gym ever asked
  "would you want X?" or "is this worth paying for?", the answer does **not** count,
  even if it is positive and enthusiastic.
- Copy the player's words **verbatim**. Paraphrase is how a gate turns into a wish.
- Record the channel and a link where possible, so the ask can be re-checked.
- Each row is dated the day the ask arrived (UTC), not the day it was logged.

## Gate

- At least **5 unprompted asks** after day 30 of the launch (i.e. after 2026-11-15).
- Decision date: after 2026-11-15, using this file as the only evidence source.
- If fewer than 5: no Pro unlock, regardless of how good the idea sounds.
