# boat.dev: filed as a crew option, November 7, 2026

Filed by Wren at the owner's direction ("Inform the crew it is a option"). This is an
option for crew assessment, not a purchase and not an authorization: no signup, no spend.
Any trial or account action needs the owner's explicit approval, as always.

## What it is (vendor pages and comparisons, read Nov 7, 2026)

boat.dev rents persistent cloud machines built for AI agents: full Linux VMs with their
own kernel, root, Docker, systemd; disk persists between sessions; snapshots every
minute; a 60 fps desktop with Chromium plus computer use and browser control APIs;
Claude Code, Codex, OpenCode and other coding agents preinstalled; agents inside are
driven from outside through one API (prompt, steer, events). Paid plans have no session
cap, machines can run for weeks, stopped machines cost nothing. Regions are EU only
(Germany, Finland, France), with EU data residency. From 20 dollars a month, 7 day trial.

## Wren's assessment (given to the owner Nov 7, before filing)

Meaningful in one lane only: the architecture question the crew already voted B
conditional on (VPS as canonical checkout, Hermes deferred, condition being a
demonstrated handoff with zero relaying from the owner). A boat machine matches that
shape as a product: one persistent home for a coding agent, a desktop browser session
that stays alive between runs, a disk that does not evaporate. Candidate uses: a sturdier
home for the OpenCode side, and the persistent Business Suite browser session the daily
pull spec needs (docs/business-suite-pull-procedure.md).

What it does not solve: it does not wake ChatGPT (it hosts coding harnesses, not
ChatGPT); it does not change Wren's setup (already a persistent machine); it does not
touch the funnel problem (watch time and returns are creative and product issues).

Warning flag: Meta treats datacenter IP logins as suspicious and boat runs only from EU
datacenters, so a Business Suite session living there might draw more checkpoints, not
fewer. Testable, not knowable from the brochure.

## The test Wren recommends before any adoption

Seven day trial, one machine, two proofs: (1) a Business Suite session that survives
the week and produces one real daily pull against the field spec; (2) one agent handoff
completed with zero messages carried by the owner. Pass both and it earns consideration
for the architecture seat the B vote contemplated; fail either and it is closed.
