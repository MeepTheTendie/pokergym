## Reading taken

The task was ambiguous in two small places; I took the most reasonable reading and
state it here:

- Item 3 "open the Odds panel by default when the question needs it": the odds
  panel holds the probabilities/EVs, so I open it for the two quiz types that are
  answered from those numbers — `select` ("which side has the lowest house edge")
  and `tieodds` ("is the tie worthwhile at N:1"). The `commission` quiz ("how many
  units do you keep after the 5% commission") is not an odds question and its
  answer is not on that panel, so I leave it collapsed.
- Item 2 "daily/session mode": implemented as `dailyMode || shortSession`, which
  covers the Daily Drill and the five-hand / master / weak-spot sessions, leaving
  the free-play challenge's Deal loop untouched.

## What changed

1. **Home daily squares show the real result** (`web/index.html`, `web/app.js`,
   `web/styles.css`). Removed the hard-coded `✓✓✓✓✕` decoration and rendered the
   squares in `renderToday()` via a new `renderDailySquares(daily, key)`: when
   `daily.lastKey === key` it reads today's `daily.history` entry and draws green
   `✓` / red `✕` per decision; before the drill is played it draws five neutral
   empty squares (new `.sq-empty` style).
2. **One gold continue after a drill video-poker hand** (`web/app.js`
   `setControls()`). In daily/session mode, `Deal` is hidden once the hand
   settles so `Next hand` is the only continue. Challenge mode is unchanged.
3. **Odds panel open by default** (`web/index.html`, `web/app.js`). Added
   `id="paytablePanel"` to the payout `<details>` and open it for baccarat
   `select`/`tieodds` quiz hands while the question is live.
4. **Copy fixes**:
   - Daily intro "five hands, one from each game" → "five hands across all four
     games" in three places (`web/index.html` explainer, `computeToday()` state,
     the drill's `dailyIntro`).
   - Video-poker coach line no longer says "best play" twice: the `doDraw` result
     line drops "Your hold was the best play" (that detail stays in the pays
     hint), so the coach reads "Result: X. … Good read. That was the best play."
   - Tie-promo quiz reason (`src/coach/baccarat.js` `tieOddQuiz`) now computes the
     actual EV instead of calling 11:1 "slightly positive": "At 11:1 the bet is
     positive expected value (+14.19% per unit staked)."
