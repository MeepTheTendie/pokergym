# Poker Gym

[Play the free browser demo](https://pokergym.history-atlas.workers.dev/web/) · [Download the current portable demo](https://github.com/MeepTheTendie/pokergym/releases/latest) · [Share player feedback](https://github.com/MeepTheTendie/pokergym/issues/1)

Practice card-game decisions in a small retro RPG. Choose a trainer, play a five-hand session in any of four gyms, and get coaching on your choices. No signup, deposits, real-money wagering or paid membership.

## Try a five-minute training session

1. Open the demo on your phone or computer and choose a trainer.
2. On the map, choose a game's five-hand practice. Read its lesson, then make your own decisions before reading the coach.
3. Visit the mistake notebook after practice. For new blackjack and baccarat mistakes, answer the original decision again before revealing the explanation; scored retries are tracked separately from gameplay accuracy.
4. Return later to review the decisions you missed. Longer gym challenges award badges; practice remains available in every game.

The gyms cover Jacks or Better video poker, blackjack, baccarat and Hold'em hand evaluation. Hold'em practice does not teach a complete betting or bluffing strategy. Coaching uses the simulator's rules and assumptions; learning strategy cannot guarantee gambling profits.

Prefer a quick lesson first? Try the [three-hand video-poker guide](https://pokergym.history-atlas.workers.dev/guides/jacks-or-better/) or [three blackjack decisions](https://pokergym.history-atlas.workers.dev/guides/blackjack/), with answers hidden until you reveal them.

## Help decide what comes next

After a real session, [leave voluntary feedback](https://github.com/MeepTheTendie/pokergym/issues/1): which game/device did you use, where was the coaching unclear, and what would make you return next week? The thread also asks about interest in a hypothetical US$5/month weekly-drill and deeper-review offer. That offer is research, not an available subscription.

GitHub feedback is public and requires an account. Omit personal details and save backups. The demo also provides an email-draft alternative that you review and send yourself.

## Saves, offline play and downloads

Progress stays in this browser, without a cloud account. Clearing browser data can remove it. Use the game's manual backup export to keep a private copy. When browser storage is blocked or full, practice still runs but progress may not persist.

The live demo shows when its offline game download is ready. Close existing game tabs to activate updates. Offline behavior has been checked in headless Chromium; physical Android installation and an Android store release remain unverified.

The release ZIP is an HTML5 browser game for hosting or local serving, not an Android installer. Actual itch.io hosting is not verified. Use the release's checksum file to check the downloaded archive.
